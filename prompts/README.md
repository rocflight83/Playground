# Prompts

These files are the intelligence's policy. The `/study-plan` skill
(`.claude/skills/study-plan/SKILL.md`) and the local app's `Intelligence`
adapter both read them; **edit here, never in a copy**. `policy.md` is
shared by every prompt; `generate.md`, `replace-session.md` and
`replace-material.md` are path-specific duties.
